#Tips

I recommend using JetBrains Pycharm
PyCharm is a cross-platform integrated development environment (IDE) built by JetBrains for Python, data science, web development, and AI/ML workflowsas well as html and other file types.
It is easy to use and has an integrated free-to-use AI

You can change the color scheme, in pycharm, it shows what color you have selected by reading the hexadecimal or the name of the color.
If you want the "store" to have a different topic, feel free to grab snippets of the css or html to understand how it works or if you like how it looks.
Changing the "store" to "sell" something else is very easy. Just rename all instances of "cube" to "something" and "cubes" to "somethings" and rename "cubes.json" to "somethings.json"
(Replace something/somethings with your actual topic/intent)
